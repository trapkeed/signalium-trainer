We are building the Signalium Trainer from scratch.

Repository:

signalium-trainer

This repository is completely independent from the existing Signalium production platform.

The existing Node.js application remains unchanged.

======================================================================
MISSION
======================================================================

The Signalium Trainer is responsible for:

• Downloading datasets exported by Signalium
• Verifying dataset integrity
• Training deep learning models
• Evaluating trained models
• Exporting production-ready model artifacts
• Uploading results back to Signalium
• Running entirely on RunPod GPU instances

This repository must NEVER connect directly to PostgreSQL.

It communicates ONLY with the Signalium REST API.
