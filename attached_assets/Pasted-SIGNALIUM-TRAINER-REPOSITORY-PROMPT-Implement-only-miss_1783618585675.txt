## RUNPOD EXECUTION MODEL

Trainer never stores RunPod API keys.

Trainer receives:

* pod_id
* endpoint
* worker_token
* expiration_timestamp
* storage_credentials
* artifact_destination

Reject expired credentials.

Reject invalid signatures.

Support:

* local_worker
* runpod_worker

Training engine must remain execution-backend agnostic.
