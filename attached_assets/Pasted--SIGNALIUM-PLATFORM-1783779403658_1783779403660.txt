
================================================================================
SIGNALIUM PLATFORM <-> TRAINER INTEGRATION CONTRACT
================================================================================

Platform URL : https://signaliumai.com
Trainer URL  : https://trainer.signaliumai.com

You are signalium-trainer. This document defines the complete contract between
you and the Signalium platform. Implement every endpoint and follow every auth
rule exactly — the platform has no fallback for malformed responses.

================================================================================
1. AUTHENTICATION — EVERY INBOUND REQUEST
================================================================================

Every HTTP request from the platform carries:

  Authorization: Bearer <JWT>
  X-Signalium-Service-Id: signalium-platform
  X-Signalium-Request-Id: <uuid>
  X-Signalium-Nonce: <32-char hex>
  X-Signalium-Timestamp: <ISO-8601>

Verify the JWT on every request:
  - Algorithm  : ES256 (P-256 keypair)
  - Issuer     : signalium
  - Audience   : signalium-trainer
  - Subject    : signalium-platform-service
  - Scope      : must include "trainer.inference"
  - TTL        : 5 minutes — do not cache beyond exp

Fetch the public JWKS (no auth required) from:
  GET https://signaliumai.com/api/sso/jwks

Cache keys by kid. Re-fetch on unknown kid to handle rotation. Reject any
request whose JWT does not verify against the current JWKS.

  401 — missing / invalid / expired token
  403 — valid token but wrong audience or missing scope

================================================================================
2. HEALTH CHECK
================================================================================

  GET https://trainer.signaliumai.com/health

Response 200:
  { "status": "ok" }

The platform probes this endpoint to check reachability. A non-2xx causes it
to show "Trainer unreachable" in the ops dashboard and fall back to local
heuristics for all inference.

================================================================================
3. PLATFORM CONFIGURATION
================================================================================

The platform resolves your URL in this priority order:
  1. Admin Managed Secrets vault key : trainer.url
     -> set to https://trainer.signaliumai.com
  2. Environment variable            : QDE_TRAINER_URL

Both the inference gateway and the research lab use the SAME base URL. There
is no separate host for research vs inference.

The platform calls these on every EA telemetry tick (~30 s per open position).
All are POST. All return the same response shape.

IMPORTANT: symbol is always CANONICAL (e.g. XAUUSD, EURUSD, US30). The
platform normalises broker-specific variants (XAUUSD_i, EURUSDm, DJ30,
US30.cash, etc.) before calling you. You will never receive raw broker symbols.

4f. Unified Inference Response (all five endpoints)
--------------------------------------------------------------------------------

  {
    "direction": "LONG",
    "confidence": 0.78,
    "risk_signal": "MEDIUM",
    "size_signal": "NORMAL",
    "entry_urgency": "PENDING",
    "exit_horizon": "INTRADAY",
    "reasoning": "Gold is holding support at 2380 with declining sell volume...",
    "warnings": [],
    "model_version": "v3.2.1",
    "latency_ms": 142,
    "positions": []
  }

Field constraints:

  Field           Type      Required  Allowed values
  --------------- --------- --------- -----------------------------------------
  reasoning       string    YES       Non-empty. Platform rejects the response
                                      and falls back to heuristics if missing.
  direction       string    no        "LONG" | "SHORT" | "NEUTRAL"
  confidence      number    no        0.0 – 1.0
  risk_signal     string    no        "LOW" | "MEDIUM" | "HIGH" | "EXTREME"
  size_signal     string    no        "MINIMAL" | "NORMAL" | "AGGRESSIVE"
  entry_urgency   string    no        "IMMEDIATE" | "PENDING" | "CONDITIONAL"
  exit_horizon    string    no        "SCALP" | "INTRADAY" | "SWING" | "HOLD"
  warnings        string[]  no        Any array of human-readable strings
  model_version   string    no        Arbitrary version identifier
  positions       array     no        Portfolio-review only (see below)

positions[] entries (portfolio-review only):
  {
    "symbol": "XAUUSD",
    "action": "TRAIL",
    "reasoning": "Position trending well with room to run",
    "confidence": 0.78
  }

Action enum (used in positions[].action and the legacy direct path):
  HOLD | ADD | REDUCE | TRAIL | BREAKEVEN | LOCK_PROFIT | CLOSE

6. EA COMMUNICATION — FULL DATA FLOW (YOUR AWARENESS ONLY)
================================================================================

You never speak directly to EAs. The platform mediates everything. This
section shows the full data path so you understand what reaches you and why.

EAs connect to the platform at:
  wss://signaliumai.com/ws/ea?apiKey=<key>&hardwareId=<mt5-terminal-id>
  or HTTP fallback: POST https://signaliumai.com/api/qde/telemetry

What the EA sends every ~30 s per open position:
  {
    "type": "telemetry",
    "requestId": "<uuid>",
    "data": {
      "symbol": "XAUUSD_i",        <- broker symbol (raw, NOT canonical)
      "balance": 10250.50,
      "equity": 10190.20,
      "margin": 320.00,
      "freeMargin": 9870.20,

7. PERFORMANCE REQUIREMENTS
================================================================================

  Endpoint group              Hard timeout  Circuit breaker
  --------------------------- ------------- --------------------------------------
  /health                     5 s           No
  /qde/* (inference)          5 s           Yes — 4 consecutive failures trip it;
                                            60 s reset. After tripping, ALL
                                            inference falls back to local
                                            heuristics for the reset duration.
  Research lab (/experiments, 15 s          No — non-2xx surfaces as
  /training/*, etc.)                        "unavailable" in the UI.

Design for high availability on the /qde/* paths. Keep p99 inference latency
well under 5 s.

8. ERROR CONVENTIONS
================================================================================

Always return Content-Type: application/json.

  Status  Situation                              Body
  ------- -------------------------------------- --------------------------------
  401     Missing / invalid / expired JWT        { "error": "Unauthorized" }
  403     Wrong audience or missing scope        { "error": "Forbidden" }
  400     Missing required field                 { "error": "<description>" }
  404     Resource not found                     { "error": "Not found" }
  500     Internal trainer error                 { "error": "<description>" }
