We have completed the first implementation of the Signalium Quant model.

Before continuing with additional architectures, refactor the implementation into a reusable Model Framework.

Do NOT remove any working functionality.

Do NOT change the training pipeline.

Instead, generalize the architecture so that the existing LSTM model becomes one implementation of a common interface.

======================================================
OBJECTIVE
======================================================

Create a modular model framework that supports multiple deep learning architectures without requiring changes to the training engine.
