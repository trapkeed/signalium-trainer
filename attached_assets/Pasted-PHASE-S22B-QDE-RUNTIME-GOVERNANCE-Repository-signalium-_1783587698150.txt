* confidence versus realized outcome

* profit factor

* each user cohort

* deterioration in prediction quality

* abnormal confidence spikes
* unstable behaviour

* stale features

* delayed features

6. MARKET REGIME COVERAGE

* black swan conditions

Generate warnings.

Continue running challenger models silently.

Record:

* agreement rate
* disagreement rate
* confidence differences
* latency differences

* calibration
* profitability

* drift
