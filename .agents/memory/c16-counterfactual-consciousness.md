## Primary vs secondary thesis (vs ThesisManager bull/bear)

`ThesisManager.bull_thesis` / `bear_thesis` = the two evidence-weighted sides of every debate.

C16 `primary_side` / `secondary_side` = which direction the QDE is **committed to** vs **monitoring**. Layer above — does NOT replace ThesisManager. `Thesis` objects are passed in per-call; this package does not own them.

## Five scenario types generated by generate_alternatives()

| Type | Condition for generation |
|------|--------------------------|
| REVERSAL | Always (seeded from primary.conflicting_evidence) |
| SIDEWAYS | Always (weighted by uncertainty_score) |
| ACCELERATION | primary_p ≥ 0.45 |
| EXHAUSTION | primary_p ≥ 0.60 |

## Three stored event types

- `ThesisFlipRecord` — when primary↔secondary switch; includes `FlipLesson`
- `ThesisReversalRecord` — quick flip-back within `REVERSAL_WINDOW_SECONDS = 300s`
- `UncertaintySpikeRecord` — when uncertainty delta ≥ `UNCERTAINTY_SPIKE_DELTA = 0.20`

## FlipLesson design

Created on every `switch_thesis()`. Surfaces `ignored_warnings` = the old primary thesis's `conflicting_evidence` items that were present before the flip. `time_to_flip = max(0.0, now - last_flip_at or created_at)` — clamped to ≥ 0 because tests may use synthetic past timestamps that predate real `created_at`. `could_have_switched_earlier = True` when ignored_warnings present AND time_to_flip ≥ REVERSAL_WINDOW_SECONDS.

## recommend_switch() triggers

- `SECONDARY_DOMINANCE`: `secondary_p > primary_p + SWITCH_MARGIN (0.15)`
- `CONFIDENCE_COLLAPSE`: `primary_p < PRIMARY_CONFIDENCE_FLOOR (0.35)`

## evaluate_alternative() formula

```
match_ratio       = evidence_matches(trigger_conditions) / max(1, len(trigger_conditions))
invalidation_ratio = evidence_matches(invalidation_signals) / max(1, len(invalidation_signals))
raw_score         = match_ratio × (1 − invalidation_ratio)
updated_weight    = 0.60 × scenario.probability_weight + 0.40 × raw_score
# SIDEWAYS bonus: + 0.10 × current_uncertainty
```

Substring matching on evidence strings (case-insensitive). Result clamped [0, 1].

## Recovery throttle (switch_thesis)

`switch_thesis()` records flip, detects reversal if: `new_primary_side == previous_previous_primary_side AND elapsed ≤ REVERSAL_WINDOW_SECONDS`. Flip-records capped at MAX_FLIP_RECORDS = 100. Probability evolution capped at MAX_PROBABILITY_POINTS = 500.

## Thresholds

- `SWITCH_MARGIN = 0.15` — margin required for switch recommendation
- `PRIMARY_CONFIDENCE_FLOOR = 0.35` — collapse trigger
- `UNCERTAINTY_SPIKE_DELTA = 0.20` — spike recording threshold
- `REVERSAL_WINDOW_SECONDS = 300.0` — flip-back window
- `MAX_FLIP_RECORDS = 100`, `MAX_REVERSAL_RECORDS = 50`, `MAX_SPIKE_RECORDS = 100`, `MAX_PROBABILITY_POINTS = 500`
